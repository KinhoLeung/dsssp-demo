# 常见问题（FAQ）

这里汇总了使用 WebHMI 过程中常见的问题与解决方案。

## 连接问题

### 问：点击“USB 连接”后提示“未找到兼容设备”怎么办？

1. 确认设备已上电并正确连接到电脑。
2. 检查 USB 数据线是否损坏，或尝试电脑的其他 USB 接口（建议使用主板直连口）。
3. 少数系统可能需要特定驱动才能识别为 HID 设备，但在大多数情况下（Windows/macOS）可免驱使用。

### 问：浏览器提示“不支持 WebHID / Web Bluetooth”？

请确认使用最新版本的 **Google Chrome** 或 **Microsoft Edge**。出于隐私与安全限制，Firefox 与 Safari 目前并不完整支持这些协议。

### 问：为什么蓝牙搜不到设备？

1. 确认设备蓝牙已开启，并处于“可被发现”状态。
2. 检查设备是否已被其他电脑/手机/平板或应用占用连接。
3. 确认电脑/手机/平板的蓝牙硬件已开启。

## 文件管理

### 问：.webhmi 文件可以跨设备使用吗？

只要设备型号一致且固件 **主版本号** 一致，该配置通常是兼容的。
