# 使用指南

欢迎使用 **WebHMI**！本指南将帮助你快速了解核心功能与操作流程，并指导你如何使用 WebHMI 高效地调试/调音你的音频设备。

## 1. 快速开始

### 平台与浏览器兼容性

WebHMI 依赖底层硬件通信协议（WebHID 与 Web Bluetooth API）。因此，能否连接设备取决于操作系统与浏览器对这些能力的支持情况。

#### 桌面端（PC / Mac / Linux）

| 操作系统      | 推荐浏览器      | USB（WebHID） | 蓝牙（WebBLE） | 备注                           |
| :------------ | :-------------- | :-----------: | :------------: | :----------------------------- |
| **Windows**   | Chrome / Edge   |      ✅       |       ✅       | 建议 Windows 10（1809）及以上 |
| **macOS**     | Chrome / Edge   |      ✅       |       ✅       |                                |
| **Linux**     | Chrome / Edge   |      ✅       |       ✅       | HID 可能需要配置 udev 规则     |

#### 移动端（手机 / 平板）

| 操作系统           | 浏览器状态              |  USB  | 蓝牙 | 建议                                                         |
| :----------------- | :---------------------- | :---: | :--: | :----------------------------------------------------------- |
| **Android**        | Chrome / Edge           |  ❌   |  ✅  | 建议使用蓝牙连接进行调试/调音                                |
| **iOS / iPadOS**   | Safari                  |  ❌   |  ❌  | 受系统限制，不支持原生的低层硬件通信能力                     |
| **iOS / iPadOS**   | **Bluefy**（第三方）    |  ❌   |  ✅  | 可在 App Store 尝试 Bluefy 浏览器以获得 BLE 支持             |

> **重要说明**：
> * **不支持的浏览器**：Safari（桌面与移动端）、Firefox、Internet Explorer，以及所有非 Chromium 内核的老旧浏览器。
> * **App 内置浏览器**：如微信、Facebook 等 App 的“内置浏览器”通常会禁用硬件接口。如果在这些 App 内打开，请在右上角菜单选择“在浏览器中打开”。

### 连接设备

在首页你可以选择三种入口进入控制界面：

1. **USB 连接**：通过 WebHID 使用 USB 线连接，速度快且更稳定。
2. **蓝牙连接（BLE）**：通过 Web Bluetooth 搜索并配对支持的蓝牙设备。
3. **演示模式**：没有实体设备时，可通过演示模式体验完整界面与功能。

## 2. 核心功能

WebHMI 提供专业级音频处理工具，覆盖从输入增益到输出限制的完整链路。

### 交互式 EQ（均衡器）

为 Music、Mic 以及各输出通道提供强大的 EQ 功能：

* **可视化曲线**：实时显示幅频响应曲线。
* **拖拽调整**：可直接拖拽曲线上的节点调整频率（Freq）与增益（Gain）。
* **精细调节**：支持调整 Q 值（带宽）并切换滤波器类型（如 Peak、LowShelf、HighShelf、LowPass、HighPass 等）。
* **双击重置**：双击节点可快速恢复默认设置。

## 3. 高级操作

### 配置管理

便捷地在不同设备之间迁移设置：

* **导出（.webhmi）**：将当前全部参数（不含敏感系统项）保存为本地文件。
* **导入**：从本地文件加载配置。系统会自动校验固件版本兼容性并给出风险提示。

### 实时同步

所有操作都会 **实时发送** 到设备：当你在网页上移动滑块或拖动 EQ 点位时，设备参数会立即同步更新，获得“所见即所得”的调试体验。
