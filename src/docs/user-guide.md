# 使用指南

欢迎使用 **WebHMI**！本指南将帮助您快速了解 WebHMI 的核心功能、操作流程以及如何高效地调试您的音频设备。

## 1. 快速入门

### 平台与浏览器兼容性

由于 WebHMI 依赖底层硬件通信协议（WebHID 和 Web Bluetooth API），其连接能力取决于操作系统与浏览器的共同支持情况。

#### 桌面端 (PC / Mac / Linux)

| 操作系统    | 推荐浏览器    | USB 连接 (WebHID) | 蓝牙连接 (WebBLE) | 备注                              |
| :---------- | :------------ | :---------------: | :---------------: | :-------------------------------- |
| **Windows** | Chrome / Edge |         ✅         |         ✅         | 建议 Windows 10 (1809) 或更高版本 |
| **macOS**   | Chrome / Edge |         ✅         |         ✅         |                                   |
| **Linux**   | Chrome / Edge |         ✅         |         ✅         | 需配置 udev 权限以访问 HID 设备   |

#### 移动端 (手机 / 平板)

| 操作系统         | 浏览器状况             | USB 连接 | 蓝牙连接 | 建议                                          |
| :--------------- | :--------------------- | :------: | :------: | :-------------------------------------------- |
| **Android**      | Chrome / Edge          |    ❌     |    ✅     | 推荐使用蓝牙连接调音                          |
| **iOS / iPadOS** | Safari                 |    ❌     |    ❌     | 苹果系统限制，暂不支持原生底层通信            |
| **iOS / iPadOS** | **Bluefy** (第三方)    |    ❌     |    ✅     | 可在 App Store 下载 Bluefy 浏览器尝试蓝牙连接 |

> **重要提示**：
> * **不支持的浏览器**：Safari (桌面及移动端)、Firefox、Internet Explorer、以及所有旧版非 Chromium 内核浏览器。
> * **应用内浏览器**：手机或者应用自带的“内置浏览器”通常禁用了底层硬件接口。若在这些应用中打开，请点击右上角选择“在浏览器中打开”。

### 连接设备

在首页，您可以选择以下三种方式进入控制界面：

1. **USB 连接**：通过 USB 线缆连接设备，利用 WebHID 协议进行高速、稳定的通信。
2. **蓝牙连接 (BLE)**：通过原生的 Web Bluetooth 搜索并配对受支持的蓝牙设备。
3. **演示模式 (Demo Mode)**：如果您手头没有物理设备，可以使用演示模式体验完整的功能界面。

## 2. 核心功能

WebHMI 提供了专业级的音频处理工具，涵盖了从输入增益到输出限制的全链路配置。

### 交互式 EQ (均衡器)

在音乐、麦克风及各个输出通道中，均配备了强大的均衡器系统：

* **可视化图形**：实时显示频率响应曲线。
* **拖拽操作**：您可以直接在曲线上通过鼠标拖拽节点来调整频率 (Freq) 和增益 (Gain)。
* **多参数精调**：支持调整 Q 值（带宽）以及切换滤波器类型（如 Peak, LowShelf, HighShelf, LowPass, HighPass 等）。
* **双击重置**：在节点上双击可快速恢复默认设置。

## 3. 高级操作

### 配置文件管理

您可以轻松地在不同设备间迁移配置：

* **导出 (.webhmi)**：将当前设备的所有参数（不含敏感系统设置）保存为本地文件。
* **导入**：从本地文件加载配置。导入时系统会自动验证固件版本兼容性，并给出风险提示。

### 实时同步

所有操作均为 **实时下发**。当您在网页上移动滑块或拖拽 EQ 点时，连接的设备会即时生效，实现“所见即所得”的调音体验。
